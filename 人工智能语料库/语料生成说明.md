# 低代码渲染树语料生成说明

## 概述

本文档说明如何生成符合 bobliao-lowCode 低代码编辑器规范的渲染树语料，用于训练自然语言到UI生成的AI模型。

## 渲染树结构理解

### 1. 核心数据结构

渲染树是一个嵌套的JSON对象，每个节点包含以下核心属性：

```typescript
interface ITreeNode {
  nodeid: string;           // 唯一节点ID
  name: string;             // 组件名称
  label: string;            // 组件显示标签
  props: object;            // 组件属性
  nodetype: "layout" | "component";  // 节点类型
  componentType: string;    // 组件类型
  containerType: string[];  // 可放置的容器类型
  isTached: boolean;        // 是否已附加
  children?: ITreeNode[];   // 子节点
}
```

### 2. 完整的渲染树格式

```json
{
  "node": {
    // 根节点内容
  },
  "classes": ""  // CSS类名（通常为空）
}
```

## 关键参考文件

### 1. 组件定义文件

**文件路径**: `low-code/src/lcSupport/lcsUtils.ts`

**作用**: 定义所有可拖拽组件的配置信息

**关键内容**:
- `components` 数组：所有可用组件的定义
- `ComponentNameMap`：组件名称映射
- `importStringMap`：组件导入路径映射

**参考要点**:
- 每个组件的 `defaultProps` 定义了默认属性
- `containerType` 定义了组件可以放置在哪些容器中
- `componentType` 决定了组件的实际类型

### 2. 属性定义文件

**文件路径**: `low-code/src/lcSupport/propsDefineFiles/index.ts`

**作用**: 定义每个组件的可配置属性结构

**关键内容**:
- `componentsPropsDefine` 对象：包含所有组件的属性定义
- 每个组件的属性结构（如 `GridProps`, `buttonProps` 等）

**参考要点**:
- 了解每个组件支持哪些属性
- 属性的数据类型和默认值
- 特殊属性如 `autoFormItemProps`, `commonInqueryItemProps` 的使用

### 3. 渲染树管理钩子

**文件路径**: `low-code/src/lcSupport/renderTreeController/renderTreeHook.ts`

**作用**: 渲染树的核心管理逻辑

**关键内容**:
- `useRenderTreeHook` 钩子
- 节点操作方法（`addNode`, `insertNodeAt`, `deleteNode` 等）
- 树结构验证和生成逻辑

## 组件分类和使用规范

### 1. 布局组件 (nodetype: "layout")

#### MainCard
- **用途**: 页面块状布局卡片
- **容器类型**: `["div", "gridItem", "pageRoot", "Stack"]`
- **常用属性**: `title`, `border`

#### AutoForm
- **用途**: 表单自动布局器
- **容器类型**: `["gridItem", "div", "MainCard", "pageRoot"]`
- **常用属性**: `layoutStyle`
- **可接受的子组件类型**: 只能接受以下组件作为子节点：
  - `TextField` - 普通文本输入框
  - `CustomNumberInput` - 数字输入框
  - `MithrilSelect` - 单选或多选下拉框
  - `MithrilAutocomplete` - 自动完成输入框
  - `AntdDateRangePacker` - 时间范围选择器
  - `NumberRangeInput` - 数字范围输入框
  - `MithrilTextArea` - 多行文本输入框
  - `MithrilYesNoSwitch` - 是/否开关
  - `SingleDatePicker` - 单日期选择器

#### CommonInquery
- **用途**: 通用查询栏组件
- **容器类型**: `["gridItem", "div", "MainCard", "pageRoot"]`
- **常用属性**: 通常为空对象
- **可接受的子组件类型**: 只能接受以下组件作为子节点：
  - `AntdDateRangePacker` - 时间范围选择器
  - `MithrilAutocomplete` - 自动完成输入框
  - `CustomNumberInput` - 数字输入框
  - `MithrilInput` - 普通文本输入框（用于查询条件）
  - `NumberRangeInput` - 数字范围输入框
  - `MithrilSelect` - 单选或多选下拉框
  - `MithrilTextArea` - 多行文本输入框
  - `SingleDatePicker` - 单日期选择器

#### Grid
- **用途**: 网格布局容器
- **容器类型**: `["div", "pageRoot", "MainCard"]`
- **常用属性**: `columns`, `rows`, `gap`

### 2. 表单组件 (nodetype: "component")

#### TextField
- **用途**: 普通文本输入框
- **容器类型**: `["gridItem", "div", "AutoForm", "li"]`
- **特殊属性**: `autoFormItemProps`, `commonInqueryItemProps`

#### MithrilSelect
- **用途**: 单选或多选下拉框
- **容器类型**: `["gridItem", "div", "CommonInquery", "AutoForm", "li"]`
- **特殊属性**: `selectItems` 数组

#### NumberRangeInput
- **用途**: 数字范围输入框
- **容器类型**: `["gridItem", "div", "CommonInquery", "AutoForm", "li"]`
- **常用属性**: `splitStr`, `units`, `placeholder`

#### AntdDateRangePacker
- **用途**: 时间范围选择器
- **容器类型**: `["gridItem", "div", "CommonInquery", "li"]`
- **常用属性**: `dateFormat`

#### MithrilAntdTable
- **用途**: 数据表格
- **容器类型**: `["gridItem", "div"]`
- **常用属性**: `columns`, `dataSource`, `sticky`, `scroll`

## 特殊属性说明

### 1. autoFormItemProps
用于 AutoForm 组件的表单项配置：
```typescript
{
  isRequiredStyle: boolean;  // 是否显示必填样式
  name: string;              // 字段名
  label: string;             // 显示标签
  selectItems?: Array<{label: string, value: string}>;  // 选项列表
}
```

### 2. commonInqueryItemProps
用于 CommonInquery 组件的查询项配置：
```typescript
{
  name: string | string[];   // 字段名（支持数组）
  defaultValue: string | string[];  // 默认值
  label: string;             // 显示标签
  selectItems?: Array<{label: string, value: string}>;  // 选项列表
  dateFormat?: string;       // 日期格式
}
```

## 生成规范

### 1. 节点ID生成
- 使用随机字符串，确保唯一性
- 建议使用有意义的前缀，如 `form_`, `table_`, `query_`

### 2. 容器类型匹配
- 确保子组件的 `containerType` 包含父组件的 `name`
- 检查 `lcsUtils.ts` 中的 `containerType` 定义
- **重要提醒**: AutoForm 和 CommonInquery 组件只能接受特定的子组件类型，详见上述组件说明

### 3. 属性完整性
- 参考 `propsDefineFiles/index.ts` 确保属性结构正确
- 对于表单组件，必须包含相应的 `autoFormItemProps` 或 `commonInqueryItemProps`

### 4. 业务逻辑合理性
- 表单字段名称要有业务意义
- 下拉选项要符合实际业务场景
- 表格列定义要合理

## 常见错误避免

### 1. JSON格式错误
- 确保所有字符串正确转义
- 检查括号匹配
- 避免多余的逗号

### 2. 结构错误
- 确保 `classes` 字段存在且为字符串
- 检查节点嵌套关系
- 验证 `containerType` 匹配
- **AutoForm/CommonInquery 子组件错误**: 确保 AutoForm 和 CommonInquery 的子组件类型在允许的组件列表中

### 3. 属性错误
- 确保 `selectItems` 格式正确
- 检查 `name` 字段的唯一性
- 验证日期格式字符串

## 生成流程建议

1. **确定页面类型**：表单页、列表页、详情页等
2. **设计布局结构**：选择合适的布局组件
3. **添加业务组件**：根据需求选择表单或展示组件
4. **配置属性**：参考属性定义文件设置正确的属性
5. **验证结构**：确保容器类型匹配和属性完整
6. **测试加载**：在低代码编辑器中验证渲染树

## 重要提醒

### AutoForm 组件限制
AutoForm 组件只能接受以下 9 种组件作为子节点：
- `TextField`, `CustomNumberInput`, `MithrilSelect`, `MithrilAutocomplete`
- `AntdDateRangePacker`, `NumberRangeInput`, `MithrilTextArea`
- `MithrilYesNoSwitch`, `SingleDatePicker`

### CommonInquery 组件限制
CommonInquery 组件只能接受以下 8 种组件作为子节点：
- `AntdDateRangePacker`, `MithrilAutocomplete`, `CustomNumberInput`
- `MithrilInput`, `NumberRangeInput`, `MithrilSelect`
- `MithrilTextArea`, `SingleDatePicker`

**注意**: 生成语料时，务必确保 AutoForm 和 CommonInquery 的子组件类型严格符合上述限制，否则会导致渲染错误。
