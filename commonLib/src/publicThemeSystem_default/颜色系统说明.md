# Berry 主题系统颜色说明文档

## 📋 概述

Berry 主题系统提供了完整的颜色体系，支持明暗两种模式，包含主色调、次色调、状态色、灰度系统等。所有颜色都通过 CSS 变量动态设置，确保主题切换时的实时响应。

## 🎨 颜色系统分类

### 1. 基础背景色系统

#### 📋 明色模式
- `--color-paper`: 主要背景色，用于卡片、对话框、抽屉等组件
- `--color-background`: 页面背景色，用于整体页面背景

#### 📋 暗色模式
- `--color-dark-level1`: 第一层暗色背景，用于浅色卡片
- `--color-dark-level2`: 第二层暗色背景，用于深色卡片
- `--color-dark-background`: 最深层背景，用于页面背景
- `--color-dark-paper`: 卡片背景，用于卡片、对话框背景

### 2. 主色调系统

#### 📋 用途说明
- **按钮**: 主要操作按钮、确认按钮
- **链接**: 重要链接、导航链接
- **图标**: 主要功能图标
- **强调**: 重要信息、高亮显示

#### 📋 CSS 变量
```css
--color-primary          /* 主色标准版本 */
--color-primary-light    /* 主色浅色版本，用于悬停状态 */
--color-primary-dark     /* 主色深色版本，用于按下状态 */
--color-primary-200      /* 主色200色阶，用于浅色背景 */
--color-primary-800      /* 主色800色阶，用于深色文字 */
```

### 3. 次色调系统

#### 📋 用途说明
- **次要按钮**: 取消按钮、辅助按钮
- **图标**: 次要功能图标
- **装饰**: 装饰性元素
- **辅助信息**: 辅助文字、提示信息

#### 📋 CSS 变量
```css
--color-secondary          /* 次色标准版本 */
--color-secondary-light    /* 次色浅色版本 */
--color-secondary-dark     /* 次色深色版本 */
--color-secondary-200      /* 次色200色阶 */
--color-secondary-800      /* 次色800色阶 */
```

### 4. 状态色系统

#### 📋 成功色 (Success)
- **用途**: 成功提示、成功按钮、成功状态图标
- **CSS 变量**:
  ```css
  --color-success          /* 成功色标准版本 */
  --color-success-light    /* 成功色浅色版本，用于背景 */
  --color-success-dark     /* 成功色深色版本，用于文字 */
  --color-success-200      /* 成功色200色阶 */
  ```

#### 📋 错误色 (Error)
- **用途**: 错误提示、错误按钮、错误状态图标
- **CSS 变量**:
  ```css
  --color-error            /* 错误色标准版本 */
  --color-error-light      /* 错误色浅色版本，用于背景 */
  --color-error-dark       /* 错误色深色版本，用于文字 */
  ```

#### 📋 警告色 (Warning)
- **用途**: 警告提示、警告按钮、警告状态图标
- **CSS 变量**:
  ```css
  --color-warning          /* 警告色标准版本 */
  --color-warning-light    /* 警告色浅色版本，用于背景 */
  --color-warning-dark     /* 警告色深色版本，用于文字 */
  ```

#### 📋 橙色系统 (Orange)
- **用途**: 特殊状态、橙色按钮、橙色图标
- **CSS 变量**:
  ```css
  --color-orange           /* 橙色标准版本 */
  --color-orange-light     /* 橙色浅色版本，用于背景 */
  ```

### 5. 文字颜色系统

#### 📋 用途说明
- **主要文字**: 正文内容、重要信息
- **次要文字**: 辅助信息、提示文字
- **标题文字**: 各级标题 (h1-h6)
- **提示文字**: 占位符、提示信息

#### 📋 CSS 变量
```css
--color-text-primary      /* 主要文字色 */
--color-text-secondary    /* 次要文字色 */
--color-text-dark         /* 深色文字 */
--color-text-hint         /* 提示文字色 */
```

### 6. 灰度系统

#### 📋 用途说明
- **背景色**: 不同层级的背景色
- **边框色**: 边框、分割线
- **文字色**: 不同重要程度的文字
- **禁用状态**: 禁用组件的颜色

#### 📋 CSS 变量
```css
--color-grey-50     /* 最浅灰，用于页面背景 */
--color-grey-100    /* 浅灰，用于卡片背景 */
--color-grey-200    /* 边框灰，用于边框、分割线 */
--color-grey-300    /* 分割线灰，用于禁用状态 */
--color-grey-500    /* 次要文字灰，用于次要文字 */
--color-grey-600    /* 主要文字灰，用于主要文字 */
--color-grey-700    /* 标题文字灰，用于标题文字 */
--color-grey-900    /* 最深文字灰，用于最深文字 */
```

### 7. 边框和分割线

#### 📋 CSS 变量
```css
--color-divider     /* 分割线颜色，用于边框、分割线 */
```

## 🔧 CSS 变量使用方法

### 1. 在 SCSS/CSS 中使用

```scss
.my-component {
    // 使用主色调
    background-color: var(--color-primary);
    color: var(--color-primary-light);
    
    // 使用文字颜色
    color: var(--color-text-primary);
    
    // 使用边框颜色
    border: 1px solid var(--color-divider);
    
    // 使用状态色
    &.success {
        background-color: var(--color-success-light);
        color: var(--color-success-dark);
    }
    
    &.error {
        background-color: var(--color-error-light);
        color: var(--color-error-dark);
    }
}
```

### 2. 在 React 组件中使用

```typescript
import React from 'react';

const MyComponent = () => {
    return (
        <div 
            style={{
                backgroundColor: 'var(--color-primary)',
                color: 'var(--color-text-primary)',
                border: '1px solid var(--color-divider)'
            }}
        >
            内容
        </div>
    );
};
```

### 3. 响应式主题切换

```scss
.my-component {
    // 基础样式
    background-color: var(--color-paper);
    color: var(--color-text-primary);
    
    // 暗色模式特殊处理
    [data-theme="dark"] & {
        background-color: var(--color-dark-level1);
        color: var(--color-text-primary);
    }
}
```

## 🎯 最佳实践

### 1. 颜色选择原则

- **主色调**: 用于主要操作、重要元素
- **次色调**: 用于次要操作、辅助元素
- **状态色**: 根据功能状态选择对应颜色
- **灰度系统**: 用于文字层级、背景层级

### 2. 主题适配

- **明色模式**: 使用浅色背景，深色文字
- **暗色模式**: 使用深色背景，浅色文字
- **状态保持**: 状态色在明暗模式下保持一致

### 3. 组件设计

```scss
// 按钮组件示例
.button {
    // 基础样式
    background-color: var(--color-primary);
    color: var(--color-paper);
    border: 1px solid var(--color-primary);
    
    // 悬停状态
    &:hover {
        background-color: var(--color-primary-light);
        border-color: var(--color-primary-dark);
    }
    
    // 按下状态
    &:active {
        background-color: var(--color-primary-dark);
    }
    
    // 禁用状态
    &:disabled {
        background-color: var(--color-grey-300);
        color: var(--color-grey-500);
        border-color: var(--color-grey-300);
    }
}
```

## 📝 注意事项

1. **CSS 变量优先级**: CSS 变量具有较高的优先级，会覆盖普通 CSS 属性
2. **主题切换**: 所有颜色都会在主题切换时自动更新
3. **浏览器兼容性**: CSS 变量在现代浏览器中支持良好
4. **性能考虑**: CSS 变量在主题切换时性能良好，无需重新渲染组件
